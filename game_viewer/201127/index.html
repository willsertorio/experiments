Overview

Three samples of visual slices from the ongoing game collection. A visual slice is not a full game yet: it sets the look, sound and core loop of the game in one playable level or match.

  1. Brief

    Who

    Client

    What

    Shares the PRD and the game their model generated from it

    Output

    • PRD
    • Game generated by the model

  2. GDD and rubrics

    Who

    AI pipeline

    What

    Writes the GDD and the rubrics from the PRD, then checks that both agree

    Output

    • The GDD, with the core loop broken into steps
    • About 35 rubrics per game (34 to 37), in four groups: core loop 6 to 9 (one per core loop step), presentation 7, design document 9, content 12

  3. Visual slice

    Who

    Visual artist

    What

    Builds the slice with a coding agent, turn by turn, then marks the core loop and presentation rubrics

    Output

    • Every turn: the prompt, the agent's reply, the artist's note, a screenshot, the code diff and the agent trajectory
    • Visual references, a moodboard and a gameplay video
    • Rubric checks: the core loop and presentation rubrics, about 14 per game (13 to 16), marked pass or fail, each with a written account of how the game meets it
    • 71 to 94 turns and 8 to 11 hours of work per sample

  4. Visual slice review

    Who

    Senior visual designer, in two layers

    What

    Plays the slice and rates it: sends it back with written feedback, or approves it with minor edits

    Output

    • A rating and written feedback for each round
    • Each sample went through 3 or 4 reviews before approval

  5. Full game

    Who

    Game dev specialist

    What

    Uses AI to build the full game from the slice's HTML: at least 15 minutes of play with enough variety and a rising difficulty curve, true to the design reference in art, interface, animation, sound and scenes, and free of bugs, glitches and unresponsive controls

    Output

    • The full game, with the design document and content rubrics graded at every turn

  6. Full game review

    Who

    Senior game dev specialist

    What

    Plays the full game and checks that it is fun, respects the design reference and is technically polished, then sends it back with written feedback or approves it

    Output

    • A rating and written feedback for each round
